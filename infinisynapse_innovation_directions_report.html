一、用大白话讲清楚：这个比赛要你做啥

一句话：做一个能上线、真人能用、并且后台真在调用 InfiniSynapse 做数据分析的小应用。不是 Demo 视频，不是 GitHub 丢仓库。

三层结构：① 前端一个输入框/上传框（网页/小程序/桌面都行）→ ② 后端把用户问题发给 /v1/query 让 InfiniSynapse 跑分析 → ③ 把结果画成表格/图表/报告返回。

最关键的隐藏规则：评分 60% 看真实用户数和活跃调用量（平台后台查得到），40% 看专家觉得你场景有价值、做得完整、有创新。所以"有人真用"比"功能多"重要得多。截止 7/31 23:59，现在约剩 3 天。

三、逐方向详解 + SWOT

方向 1 ｜ 小红书"种草翻车"检测助手

介绍：贴链接或笔记文本 → 分析是否夸大宣传、有无绝对化用语、疑似软广，给"可信度评分 + 避坑清单"。
特点：打"反种草"情绪，年轻人共鸣强、易传播。
预计耗时：1–1.5 天（我推断，结构同差评体检）。
技术/数据：前端上传/链接 → /v1/query 语义风险分类；数据用公开笔记样本或用户自贴文本。

现有作品 SWOT省钱比价/财格：S 轻量好演示；W 未做"可信度"维度；O 情绪流量大；T 平台内容政策边界
本方向 SWOTS 切口新、易病毒传播；W 需定义"翻车"标准；O 种草治理热点；T 误判引发争议

方向 2 ｜ 招聘 JD"画饼"解码器

介绍：贴 JD → 标出模糊承诺（"弹性""成长空间"）、推算真实薪资区间、提示加班/外包信号。
特点：和"简历-JD 匹配"互补，专拆公司话术。
预计耗时：1 天。
技术/数据：JD 文本 → 规则+LLM 分类；公开 JD 做样本。

现有作品 SWOT简历-JD匹配：S 刚需；W 只帮改简历不揭公司；O 求职季；T 同质化
本方向 SWOTS 反向视角稀缺；W 话术库要积累；O 打工人爽点；T 公司方不适

方向 3 ｜ 家庭"隐形开支"审计

介绍：上传账单/订阅列表 → 找出"忘了退的会员""重复付费""小额累加"，算一年浪费多少。
特点：从个人财务切到"订阅陷阱"，场景具体。
预计耗时：1–1.5 天。
技术/数据：账单/Excel → 分类聚合；示例数据集即可。

现有作品 SWOT智析账本：S 已做消费结构；W 偏总览不戳痛点；O 订阅经济普遍；T 接真实账单有隐私顾虑
本方向 SWOTS 痛点尖；W 数据获取门槛；O 年终复盘季；T 隐私

方向 4 ｜ 考研/考公"报录比地狱图"

介绍：输入专业/院校 → 拉公开招录数据，画竞争热力图，标注"卷王" vs "性价比"。
特点：把"志愿填报"思路迁到考研考公，可视化强。
预计耗时：2 天（数据清洗偏重）。
技术/数据：公开招录/分数线 → 图表；需联网或预置数据集。

现有作品 SWOT上岸参谋/高考助手：S 已验证；W 多聚焦高考；O 考研考公人群大；T 数据时效
本方向 SWOTS 热力图直观；W 数据整合累；O 考试季；T 数据不准被喷

方向 5 ｜ 二手商品"值不值"鉴定

介绍：贴闲鱼/转转链接 → 比新货价、看成色评价、算折旧合理区间，给"入手建议"。
特点：和"比价"互补，做二手垂直。
预计耗时：1.5 天。
技术/数据：商品页抓取/用户贴参数 → 比价+评价挖掘。

现有作品 SWOT省钱比价/商品侦探：S 成熟；W 偏新品；O 二手交易火；T 平台反爬
本方向 SWOTS 垂直细分；W 成色难量化；O 性价比焦虑；T 反爬

方向 6 ｜ 情侣/合租"公平账单"仲裁

介绍：导入共同开销 → 按自定义权重（收入/usage）算谁该多付，出"和睦建议"。
特点：生活决策里的"冲突场景"，有话题性。
预计耗时：1 天。
技术/数据：账单 → 权重计算+自然语言建议。

现有作品 SWOTLifeFlow/析数/决策打分：S 决策类多；W 少做"人际冲突"；O 合租情侣刚需；T 权重主观
本方向 SWOTS 情感传播点；W 易引争议；O 社交媒体好料；T 主观性

方向 7 ｜ 小商家"差评自救"周报

介绍：商家贴店铺评价 → 每周自动出"差评聚类+改进动作+话术模板"。
特点：把"差评体检"从消费者视角翻到商家视角，B 端轻量。
预计耗时：1.5 天。
技术/数据：评价文本 → 聚类+建议生成；可手动贴。

现有作品 SWOT店铺差评体检：S 已验证框架；W 偏买家；O 小商家多；T 需持续数据
本方向 SWOTS 视角反转；W 商家获客难；O 私域运营热；T 留存

方向 8 ｜ 短视频"爆款公式"拆解

介绍：贴视频链接/文案 → 拆结构（钩子/节奏/槽点），给"复制建议"。
特点：内容创作者的"逆向工程"工具。
预计耗时：1.5–2 天。
技术/数据：视频文案/字幕 → 结构标注；示例用公开视频。

现有作品 SWOT语感工坊/财格：S 创作向有；W 少做视频结构；O 短视频创作者海量；T 平台规则变
本方向 SWOTS 创作者痛点；W 公式主观；O 知识付费联动；T 易过时

方向 9 ｜ 城市"通勤幸福感"计算器

介绍：输入起点终点/预算 → 算通勤时间成本+房租权衡+宜居评分，出"搬不搬"建议。
特点：把"广佛租房通勤"升级为多城市通用+幸福感维度。
预计耗时：2 天（地图/租金数据整合）。
技术/数据：租房+地图+薪资数据 → 多维评分；可用示例数据集。

现有作品 SWOT住哪儿/租房通勤：S 已验证；W 单城市；O 跨城流动大；T 数据杂
本方向 SWOTS 多城+情绪维度；W 数据重；O 换城季；T 整合成本

方向 10 ｜ 个人"数字坟场"清理助手

介绍：导出各平台订阅/账号清单 → 标出"早不用却仍在扣费/泄露风险"的账号，给注销指引。
特点：隐私+极简主义情绪，2026 热门议题。
预计耗时：1–1.5 天。
技术/数据：清单/截图 → 风险标注；用户自填为主。

现有作品 SWOT智析账本/隐私类少：S 隐私赛道空白；W 需用户整理；O 数据隐私焦虑升；T 跨平台难自动
本方向 SWOTS 情绪+空白；W 需用户整理；O 隐私焦虑；T 跨平台自动难

四、总体策略建议（我推断是）

  • 冲奖优先级：剩 3 天，优先"一天可完成"的 方向 2 / 6（结构最简单、demo 数据好找）；想冲名次选 方向 1 / 7 / 3（情绪传播强，易拉真实用户）。
  • 避开红海：比价/尽调/高考已有成熟作品，新做需强差异化（如方向 5 二手、方向 4 考研考公）。
  • 真实用户是命门：每个方向上线后，立刻让 5–10 个真实朋友试用并触发 API 调用——这直接喂饱 60% 的用户指标分。
  • 技术克制：全部走"前端输入 → /v1/query → 表格/报告"骨架，别堆多智能体；用 Vercel/OnRender 免费拿公网 URL。
我推断的"创新"定义：在评分机制下，创新 = 稀缺场景 × 真实可用 × 轻量可交付，而非技术复杂度。上面 10 个都按此筛选，任意挑一个切垂直都能在 3 天内交卷。
