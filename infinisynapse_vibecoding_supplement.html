  • 愿景：给世界所有企业提供"最好、最便宜、最智能"的企业级数据分析服务。

🎯 三个可直接开做的方向（按时间紧迫度排序）

方案 A — 店铺差评体检助手（选题 1）· 最稳

  • 做什么：用户粘贴某商品评价 → AI 归类吐槽点、算负面占比、给改进建议。
  • 为什么选它：官方标注"一天可完成"，数据好造、场景好讲，新手首选。
  • 差异化（我推断是）：别做全品类，收成"只做母婴 / 只做数码配件"的差评体检，更容易记住、也避免和官方样板撞脸。

方案 B — 简历–JD 匹配诊断（选题 5）· 学生刚需

  • 做什么：上传简历 + 目标 JD → 打匹配分、标缺失关键词、给修改建议。
  • 为什么选它：官方标注"一天可完成"，demo 数据极好找（招聘网站 JD + 自己的简历即可）。
  • 差异化（我推断是）：做成"校招实习版"，只针对应届生 + 互联网大厂 JD，场景更聚焦。

方案 C — 租房/offer 决策打分器（选题 10）· 今晚收尾明天交

  • 做什么：丢 2–3 个候选进去，按用户权重打分并给建议。
  • 为什么选它：官方标注"一天可完成"，最轻量、最好演示。
  • 差异化（我推断是）：收窄成"只做租房对比"或"只做 offer 打分"，比泛决策更容易交卷。
我推断的关键判断：鉴于当前只剩约 3 天（7/28→7/31），优先选标注"一天可完成"的 选题 1 / 5 / 10，比冲"一个周末"档（选题 2/3/4/7/8）更可能在截止前达标并拉到真实用户调用—— 而真实 API 调用记录直接拉高占 60% 的用户指标分，比堆功能更管用。若你已有前端/Vibe Coding 经验，再考虑选题 2 / 7 / 8 冲名次。
